# LFIO — инструкция пользователя

LFIO — набор команд для импорта и экспорта фильтров слоёв в AutoCAD и nanoCAD.

## Состав

В релизе доступны сборки для:

- **LFIO_NC** — сборка `LFIO_NC.dll`;
- **LFIO_AC** — сборка `LFIO_AC2018.dll`.

Используйте сборку, соответствующую установленному CAD.

## Установка

1. Распакуйте архив релиза.
2. Выберите нужную сборку в каталоге соответствующего CAD.
3. Загрузите DLL в CAD.

Для загрузки .NET-сборки можно использовать команду `NETLOAD` и указать путь к соответствующей DLL.

После загрузки сборки команды LFIO доступны в командной строке CAD.

> При необходимости загрузки LFIO при каждом запуске CAD настройте автоматическую загрузку сборки средствами самого CAD.

## Команды

### `drz_LayerImport`

Импорт фильтров слоёв из внешнего чертежа в активный чертёж.

Поддерживаются файлы:

- DWG;
- DWS;
- DWT;
- DXF.

После запуска команды выберите файл-источник.

### `drz_FiltImp`

Импорт фильтров слоёв из файла обмена `.lfe` в активный чертёж.

### `drz_FiltExp`

Экспорт фильтров слоёв из активного чертежа в файл обмена `.lfe`.

Полученный файл можно использовать для переноса фильтров в другой чертёж с помощью `drz_FiltImp`.

## Типовой сценарий переноса фильтров

1. Откройте исходный чертёж.
2. Загрузите LFIO.
3. Выполните `drz_FiltExp`.
4. Сохраните созданный файл `.lfe`.
5. Откройте целевой чертёж.
6. Загрузите LFIO.
7. Выполните `drz_FiltImp`.
8. Выберите ранее сохранённый файл `.lfe`.

Для переноса фильтров непосредственно из другого чертежа вместо экспорта/импорта `.lfe` можно использовать `drz_LayerImport`.

## Важно

LFIO работает с фильтрами слоёв текущего чертежа. Перед массовым импортом рекомендуется сохранить рабочий чертёж.

Используйте DLL, предназначенную для вашего CAD. Сборки AutoCAD и nanoCAD используют соответствующие API хоста и не являются взаимозаменяемыми.
