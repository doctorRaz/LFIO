# LFIO

LFIO — набор инструментов для работы с CAD, связанных с импортом и экспортом фильтров слоёв.

> Проект находится в разработке. Используй код на свой страх и риск.

## Команды

| Команда | Назначение |
|---|---|
| `drz_LayerImport` | Импорт фильтров слоёв из DWG/DWS/DWT/DXF в активный чертёж |
| `drz_FiltImp` | Импорт фильтров слоёв из файла обмена `.lfe` |
| `drz_FiltExp` | Экспорт фильтров слоёв активного чертежа в файл обмена `.lfe` |
